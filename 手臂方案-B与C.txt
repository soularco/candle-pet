 一、现状（已禁用）
────────────────────────────────────────────────────────

 已验证可行的部分           状态
   ─────────────────────    ────
   物理链驱动参数             ✅ 有效（但只作用于已被绑定的部件）
   参数读写 get/set          ✅ 有效
   部件名识别 getString()    ✅ 有效
   精确选中左右袖            ✅ 只选中 #110 / #111
   顶点读写                  ✅ 有效（可写、可读回）
   内旋 / 外旋               ✅ 方向正确
   不再带动头发和腿           ✅ 已修复

 做不出来的部分
   ─────────────────────────────────────────
   · 手抬到脸前（捂脸）
   · 手臂分段弯曲（肘部）
   · 比耶、托腮等需要手部姿态的动作

 原因（不是代码问题，是素材限制）
   · 左右袖各是**一整块 0.64 长的布料**
   · 模型**没有分段关节**：没有上臂 / 前臂 / 手的独立部件
   · 刚性旋转 → 袖口甩出画外（x=0.77，而角色只有 ±0.36）
   · 弯曲旋转 → 只有下半段动，上半段不动
   · "手到脸前"需要**多关节折叠**，单块布料做不到

 当前处理
   · cubism-renderer.mjs 顶部有开关 ARM_POSING_ENABLED = false
   · 动作表里的 armLift 数据**保留**，改成 true 即可恢复
   · 其余 22 个动作的正常部分（头部、身体、表情、口型）不受影响

────────────────────────────────────────────────────────
 二、方案 C：手工补画手臂贴图
────────────────────────────────────────────────────────
 思路
   为需要手部姿态的动作，单独画几张手臂/手的贴图，
   在动作播放期间叠加显示在原模型之上。

 优点
   · 不改模型，不动现有全部动作数据
   · 效果完全可控 —— 想画成什么样就是什么样
   · 可以精确做出"手贴在脸上"这个姿态
   · 与现有渲染管线兼容（只是多画一层）

 缺点
   · 需要美术资源（可以用 AI 生成 + 人工修，或手绘）
   · 风格必须与模型一致（这是最大的难点）
   · 每换一个模型都要重画

 需要画的贴图（建议先做 3 张）
     1. 双手捂脸（正面）
     2. 单手托腮（侧）
     3. 单手比耶（侧）

 技术步骤
   1. 从 pet.model3.json 里找到纹理路径（pet.8192/texture_00.png）
      从现有纹理上裁出袖子和手的部分，作为风格参考
   2. 用参考图生成/绘制新贴图（PNG，带透明通道）
   3. 在 desktop/assets/local-model/ 下新建 overlay/ 目录存放
   4. 渲染端新增一层绘制：
        · 在 cubism-renderer.mjs 的 draw() 之后，
          用同一套投影矩阵画一张 2D 贴图
        · 位置按动作参数插值（淡入淡出 + 位移）
   5. 动作表里新增 overlay 通道：
        handToFace: { overlay: { image: 'hands-cover', in: 0.2, out: 0.8 } }
   6. 与原手臂的关系：
        · 叠加显示时把原袖子隐藏（setPartOpacityByIndex(5, 0)）
        · 或者不隐藏 —— 先试，看哪种自然

 工作量估计
     贴图绘制      1-2 天（AI 生成 + 修边）
     渲染叠加层    半天
     动作接线      半天
     ────────────────────
     合计          2-3 天

 风险
   · 风格不一致 —— 最可能失败的地方
     缓解：先用参数化调整（亮度/色调/描边）逼近，再考虑重画

────────────────────────────────────────────────────────
 三、方案 B：换一个手臂分段的模型
────────────────────────────────────────────────────────
 思路
   换成一个**标准 Live2D 全身模型**，
   带完整的手臂变形器（上臂 / 前臂 / 手，或至少 armL / armR 参数）。

 优点
   · 一劳永逸 —— 之后所有动作都能用常规参数实现
   · 不需要叠加层，不需要额外美术
   · 现有的 Phys、顶点方案都不再需要
   · 动作可以做得非常精细（关节角度、手部姿态）

 缺点
   · **等于重做全部动作数据**（22 个动作的幅度要重新标定）
   · 需要找到风格合适的模型
   · 模型授权问题（商用/个人使用）
   · 试用指纹机制要重新走一遍 configure-model 流程

 需要的模型条件
     必须
       · Cubism 3/4/5 格式（.moc3 + .model3.json + .physics3.json）
       · 有手臂参数，命名可读（ArmLA / ArmRA 或类似）
       · 分辨率不低于当前（8192 纹理）
       · 与"烛"的风格接近（黑红、少女、哥特）
     最好
       · 有表情文件（exp3）
       · 有动作文件（motion3）—— 有的话动作可以直接用官方的
       · 脸上有独立的眼、眉、嘴参数

 迁移步骤
   1. 选模型，放到 desktop/assets/local-model/
   2. 改 pet.model3.json 的文件引用
   3. 跑 tools/refresh-model-fingerprint.mjs 重算指纹
   4. 核对参数表：
        · ParamAngleX/Y/Z、ParamEyeL/R、ParamMouth 是否同名
        · 手臂参数的实际名字
   5. 改 cubism-renderer.mjs 里的参数映射表
   6. 重新标定 22 个动作的幅度：
        · 头部角度按新模型的范围调
        · 手臂改用常规参数（不再需要 armLift）
   7. 重跑语音（如果外观变了，台词可能需要微调）
   8. 打包

 工作量估计
     找模型 + 授权      不确定（0.5-3 天）
     迁移 + 调参        1 天
     动作重新标定       2 天
     联调 + 打包        1 天
     ────────────────────────
     合计               4-7 天（不含找模型的时间）

 风险
   · 找到的模型风格不合 —— 最可能返工的地方
   · 参数命名差异大 —— 需要逐个核对
   · 试用指纹机制 —— 换模型后要重新验证

 四、对比与建议
────────────────────────────────────────────────────────

              方案 C（补画贴图）      方案 B（换模型）
   ─────────  ─────────────────────   ─────────────────────
   工作量      2-3 天                  4-7 天（+找模型）
   效果上限    只能做几张固定姿态       任意姿态，完全自由
   风险        风格不一致              模型不合适
   可逆性      可逆（叠加层可关）       不可逆（动作要重做）
   长期成本    每换模型都要重画         一次投入长期受益

 建议路线
   第一步  先做 C 的**一张**贴图（双手捂脸）验证风格能不能对上
           · 对得上 → 继续做另外两张，2-3 天收工
           · 对不上 → 转 B

   第二步 如果决定转 B，
           优先找**自带动作文件（motion3.json）**的模型 ——
           那样连动作设计都省了

 不建议
   · 继续在顶点方案上投入 —— 已被证明受限于素材本身
   · 用几何变形硬凑"捂脸" —— 试了 6 轮，做不到

────────────────────────────────────────────────────────
 五、当前可用的替代表达（成本 0，现在就能用）
────────────────────────────────────────────────────────

 既然手臂只能内收/外张，捂脸这类动作可以改用组合表达：

   handToFace   低头 + 闭眼 + 袖子内收 + 身体微侧
   coverUp      同上，角度更大
   fullCover    低头 + 闭眼 + 缩小 + 袖子内收
   peaceSign    袖子外张 + 歪头 + 眨眼 + 笑眼

 这些组合在现有素材下是**能做出情绪**的 ——
 观众读到的是"她不好意思了"，而不一定需要看到手贴在脸上。
