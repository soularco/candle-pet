【你报的六个问题，逐个查清并修好】

 ── 1. 面板不能像文件窗口一样拉大缩小 ──

   原因：抽屉尺寸写死在主进程的布局计算里
         desktop/electron/layout.mjs:
           const dw = Math.min(240, sw - 20), dh = Math.min(270, sh);
         窗口大小 = 角色框 + 抽屉框 的并集
         → 抽屉 240×270 → 整个窗口只有 240px 宽
         面板里的东西再怎么排都放不下

   修复：
     · 抽屉改回 460×600（注释里写着是被人为减半的）
     · 窗口随之变成 696×600
     · 右下角加了拖拽手柄，拖动改变面板 CSS 变量并存入 localStorage

 ── 2. 面板内部比例不对、文字被大量遮挡 ★ 核心 ──

   实测：面板 270px 高，但对话区只有 3px
   原因（两层）：
     · 视口只有 240×512 —— 面板根本放不下
     · #reply 和 #pet-settings 都是 flex:1，平分剩余空间
       而 header/status/form/footer 全是 flex:0 不压缩
       合起来把对话区压成一条线

   修复：
     · 窗口放大（见上）
     · 对话区优先：flex: 3 1 0
     · 设置区让位并自己滚动，保底 150px

   实测：对话区 3px → 135px（有消息时）✓
         设置区 9px → 200px ✓

 ── 3. 有些字与按钮太小太浅找不到 ──

   原来：panel-title 10px / status 9px / reply 10px
         chat-label 8px / hint 8px / settings 8px / summary 8px
         颜色 #8192aa #8495ac #98a7bb #7588a2

   修复：字号提到 11-13px，颜色提到 AA 对比度
   实测：回复正文 13px / 设置项 12px / 提示 11px / 按钮 12px ✓

 ── 4. 回答时不会说话 ──

   原因（三条叠在一起）：
     · ambient.json 里 speech.enabled = false 且 speech.replies = false
       LocalSpeaker: wantsReplies() = enabled && replies → 恒为 false
     · 就算开着，回复走的也是系统语音，机械音
     · 音量只有 0.25

   修复：
     · 打开三个开关，音量提到 0.85
     · 回复改走 speak_cached —— 和台词用同一个云端音色，
       听起来是同一个人，而不是机器人
     · 云端没出声时回退到本地语音，不会没有声音

 ── 5. 面板纯白不好看 ──

   原因：底色是 #f4f8fff2 浅蓝白，和黑红的角色放在一起很跳

   修复：改成深色主题，并让配色【自动跟着模型走】
     做法：从渲染器已解码的模型纹理取色
       · 降采样到 64×64
       · 统计色相直方图（按饱和度加权）
       · 暗部像素的均值当底色
     实测（本模型）：
       主色相 340°（红紫）→ 强调色 hsl(340 58% 52%)
       暗部均值 [33,27,37] → 面板底色 rgb(33 27 37)
     ★ 面板现在是和角色同一族颜色，换模型会自动重新取色

 ── 6. 透明度可调 ──

   面板设置里新增「面板透明度」滑杆（30%–100%）
   实测：50% → rgba(33,27,37,0.5) ✓
   与尺寸一起存进 localStorage，下次打开保持

【顺带修的】

 · 快捷条、打开按钮、加载提示也一起换成深色，否则和面板两个世界
 · 面板里新增「面板大小 / 恢复默认」按钮
 · 模型大小下限 60% → 50%（宿主原来的硬限制 220px 也放宽到 180px）

【踩到的两个坑】

 1. PowerShell 的 Get-Content/WriteAllText 把 UTF-8 当 GBK 读，
    往返一次中文全成乱码，electron/main.mjs 就此损坏。
    → 从备份恢复，改用 node 读写（UTF-8 安全）。
    ★ 这个教训之前就吃过一次，这次又犯了，已记在文档里。

 2. 配色一直不生效：applyModelTheme 是 const，定义在文件靠后，
    调用点在它前面 → 暂时性死区，静默抛异常。
    → 用 setTimeout 推迟到脚本求值完成后再调。
