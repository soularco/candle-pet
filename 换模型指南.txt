 换模型指南：为什么功能组不会消失
════════════════════════════════════════════════════════
 生成时间：2025-10-04

────────────────────────────────────────────────────────
 一、关键事实：功能组与模型是分开的
────────────────────────────────────────────────────────

   内容                       存在哪里                依赖模型吗
   ────────────────────────   ─────────────────────   ──────────
   台词库（742 条）            ambient.json            ❌ 不依赖
   反应库（83 条）             ambient.json            ❌ 不依赖
   场景组（46 个）             ambient.json            ❌ 不依赖
   记忆系统（14 主题）         ambient.json            ❌ 不依赖
   动作定义（22 个）           interaction-motion.mjs  ❌ 不依赖
   动作曲线（头部/身体/表情）  interaction-motion.mjs  ❌ 不依赖
   ────────────────────────   ─────────────────────   ──────────
   参数名（ParamAngleX…）      cubism-renderer.mjs     ✅ 依赖
   模型文件（moc3/physics3）   assets/local-model/     ✅ 依赖
   预设目录（presets.json）    assets/local-model/     ✅ 依赖

   ★ 台词、反应、场景、记忆、动作定义**全部与模型无关** ✓
     它们写在数据文件里，换模型时一个字节都不会变 ✓

────────────────────────────────────────────────────────
 二、真正会导致"功能消失"的三个原因（已全部修复）
────────────────────────────────────────────────────────

 ── 原因 1：模型指纹不匹配时直接抛异常 ──

   原来：cubism-renderer.mjs 里
         if (fingerprint !== presetCatalog.modelFingerprint) throw new Error(...)

   后果：抛异常 → 渲染器整个挂掉 → **加载它的那段代码之后的全部不执行**
         → 界面初始化中断 → 看起来"什么都没了"

   现在：降级为警告
         · 记一条日志 model-fingerprint-mismatch
         · policyValid = false（自动策略停用，但不影响台词和动作）
         · **继续加载** ✓

   注：这是**模型指纹**，与试用绑定是两回事。
       试用绑定仍由 trial-launcher.js 严格校验，没有放松。

 ── 原因 2：模型加载失败会中断整个初始化 ──

   原来：renderer = new JellyfishRenderer(...); await renderer.load(); ...

   后果：load() 抛错 → 后面所有初始化不执行
         → 快捷栏、面板、台词调度器全都不建 → 功能组消失

   现在：try / catch 包起来
         · 失败时 report('model-error') 记录
         · renderer = null
         · **继续执行后续初始化** ✓
         → 界面上没有角色，但台词、反应、面板、快捷栏全都正常 ✓

 ── 原因 3：参数名不存在时静默失败 ──

   原来：set() 里 if (i >= 0) 才写 —— 已经是容错的，但没有任何提示

   现在：显式容错 + 记录
         · 写不进去时返回 false
         · 第一次遇到缺失的参数名记一条日志 model-parameter-missing
         · 之后不再重复记录（避免刷屏）
         → 换模型后打开日志就知道缺哪些参数 ✓

────────────────────────────────────────────────────────
 三、切换到另一个模型的完整步骤
────────────────────────────────────────────────────────

 第 1 步  放模型
    把新模型的全部文件放进：
      windows\code\desktop-pet\desktop\assets\local-model\

    必须包含：
      · .moc3          模型本体
      · .model3.json   模型描述
      · .physics3.json 物理（可用旧的，但参数名要对得上）
      · 纹理目录（如 pet.8192\）
      · .exp3.json     表情（可选）

 第 2 步  改引用
    编辑 pet.model3.json，把 FileReferences 里的路径
    指向新文件名。

 第 3 步  重算指纹
    在 windows\code\desktop-pet 下运行：
      node tools\refresh-model-fingerprint.mjs

    它会重新计算并写回 presets.json。
    ★ 只改指纹，保留 items 配置 ✓

 第 4 步  核对参数名
    打开日志（windows\.local\logs\electron.log），
    看有没有 model-parameter-missing。

    有的话，在 cubism-renderer.mjs 里找参数映射表，
    把名字改成新模型对应的。

    常见对应：
      头部转向   ParamAngleX / ParamAngleY / ParamAngleZ
      眼开闭     ParamEyeLOpen / ParamEyeROpen
      嘴开合     ParamMouthOpenY
      身体摇摆   ParamBodyAngleX / Y / Z

 第 5 步  调动作幅度
    新模型的角度范围可能不同。如果动作看起来太夸张或太小，
    改 interaction-motion.mjs 里对应动作的 curve 数值。

    ★ 不用重做台词、反应、场景、记忆 —— 它们与模型无关 ✓

 第 6 步  打包
      node tools/pack-archive.mjs

────────────────────────────────────────────────────────
 五、面板尺寸控制
────────────────────────────────────────────────────────

  位置：设置面板 → 模型大小滑杆（60% ~ 220%）

  原理：与角落的拖拽手柄走**同一条消息**
        （resize_model + begin/commit）
        所以两者不会不一致

  ★ 注意：必须先发 begin 再发 commit
    宿主的分支是：
      if (phase === 'begin') beforeResize = prefs.width;
      else if (beforeResize !== undefined) { ...应用... }
    少了 begin 就整个跳过 —— 这是第一次做时踩的坑。

  持久化：commit 时写入 prefs，下次启动保持
