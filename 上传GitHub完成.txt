【四、推送过程中排掉的三个障碍】

  1. 网络不通
     git 默认不读 Windows 系统代理 ✗
     系统代理是 127.0.0.1:7890 且在监听 ✓
     处理：git config --global http.proxy http://127.0.0.1:7890

  2. 传输中断（index-pack failed）
     报错每次都指向同一个对象 2199c409 ✗
     该对象本地不存在

  3. ★ 根因：本地是【浅克隆】
     is-shallow: true，只有 1 个提交
     浅克隆无法推送到 GitHub —— 服务器期望的对象本地没有
     处理：git fetch --unshallow upstream
          → is-shallow: false，30 个提交，36.91 MiB

  之后推送一次成功，耗时 16 秒 ✓
