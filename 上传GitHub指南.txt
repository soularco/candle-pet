 三、你要做的：推送（我这边网络到不了 GitHub）
────────────────────────────────────────────────────────

  尝试推送时的错误：

    fatal: unable to access
    'https://github.com/soularco/candle-pet.git/':
    Recv failure: Connection was reset

  这是**网络问题**（GitHub 在当前网络下连不上），不是配置问题。

 ── 步骤 1：先在 GitHub 上建仓库 ──

   打开 https://github.com/new
     Repository name: candle-pet
     Description:     A desktop companion that speaks, remembers, and forgets.
                      Forked from AAAAGENT (https://github.com/phoiex/AAAAGENT)
     Public / Private: 随意（许可要求署名，公开更容易满足"明显位置"）
     ★ 不要勾选 Add a README / .gitignore / license
       （本地已经有了，勾了会冲突）

 ── 步骤 2：解决网络 ──

   任选一种：

   A. 用代理（推荐）
      在 PowerShell 里设置，然后推送：
        git config --global http.proxy http://127.0.0.1:你的端口
        git config --global https.proxy http://127.0.0.1:你的端口
      推送完成后可以取消：
        git config --global --unset http.proxy
        git config --global --unset https.proxy

   B. 用 SSH 而不是 HTTPS
      把远端改成 SSH：
        git remote set-url origin git@github.com:soularco/candle-pet.git
      ★ SSH 走 22 端口，有时比 HTTPS 更容易连通

   C. 用 GitHub Desktop / 其他客户端推送

 ── 步骤 3：推送 ──

   在 D:\aaa\AAAAGENT 下执行：

     git push -u origin main

   第一次会要求登录：
     · 用户名：soularco
     · 密码：**不是账号密码**，而是 Personal Access Token
       到 https://github.com/settings/tokens 生成一个
       勾选 repo 权限即可

 ── 步骤 4：推送后检查 ──

   打开 https://github.com/soularco/candle-pet
   确认：

     ✅ 仓库首页 README 顶部有醒目的出处声明
     ✅ NOTICE.md 存在且可读
     ✅ LICENSE 是原版许可（没有被改掉）
     ✅ **没有** local-model 目录、没有 .moc3、没有 .local
     ✅ 文件数约 52 个新增（加上原版的 888 个）
